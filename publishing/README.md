# publishing/

Ready-to-paste descriptions for the catalogues these datasets are mirrored to.
Kept here rather than retyped each time: the same facts written twice drift apart,
and these carry the licence statements verbatim — the part that must not drift.

| File | For |
|---|---|
| `kaggle-size-grids.md` | Kaggle, the CC BY-SA dataset |
| `kaggle-brand-size-charts.md` | Kaggle, the brand charts |

Each file starts with `TITLE:`, `SUBTITLE:` and `LICENCE:` lines, then the body.

**On the brand dataset's licence field:** pick *Other (specified in description)*.
Not CC0, not CC BY, not any Creative Commons one — the numbers are not ours to
license, and the description says so in its first paragraph.
